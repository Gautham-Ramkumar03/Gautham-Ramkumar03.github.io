GPS-LiDAR Fusion

Covariance-Aware Localization with TPS Georeferencing

PerceptionSLAMROS2Production

Problem

Autonomous robots deployed across diverse environments (open construction sites, semi-covered factory floors, underground basements) face a fundamental localization challenge. GPS provides global accuracy outdoors but fails indoors, while LiDAR scan-matching works well in structured environments but accumulates drift over large distances. No single modality is reliable everywhere.

Approach

TPS-RBF Georeferencing

Traditional GPS-LiDAR fusion uses a rigid affine transform to map between LiDAR map coordinates and UTM. This breaks down when drift varies spatially across the map. Instead, this system uses Thin Plate Spline (TPS) interpolants with radial basis functions to model spatially varying drift, producing smooth, locally accurate coordinate transformations.

Covariance-Aware Source Selection

Rather than blindly fusing both sources, the system compares real-time quality metrics from each modality and selects the more confident source. Hysteresis and exponential easing prevent oscillation during transitions:

  • GPS covariance: computed per-measurement from NMEA data including fix quality, HDOP, and satellite count
  • Scan-matching covariance: derived from fitness score, convergence behavior, displacement magnitude, and point count

EKF Integration

The selected pose is fused with LiDAR-inertial odometry and IMU data through an Extended Kalman Filter, producing a smooth, unified state estimate that remains continuous even during source transitions.

Results

The system delivers continuous, robust localization across all deployment environments, from open sites with RTK-grade GPS coverage to indoor and semi-covered areas where GPS is completely unavailable. Source transitions are smooth and imperceptible to downstream navigation modules.
