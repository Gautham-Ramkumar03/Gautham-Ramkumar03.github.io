Lawnmower & MMR

Production Autonomy Stack for Commercial Robots

ROS2PerceptionProduction

Problem

Flo Mobility ships two distinct commercial robot products, an Autonomous Lawnmower and a Material Movement Robot (MMR), that share a common autonomy stack. Both require reliable, production-grade navigation, localization, and obstacle handling across very different environments.

Approach

Full-Stack Ownership

End-to-end responsibility across the shared autonomy stack: navigation, localization, sensor drivers, obstacle avoidance, and mission planning. Every component from sensor input to motor output passes through code I maintain and improve.

Hardware Integration

Built key hardware interfaces including OAK-D camera drivers and CAN bus drivers for motor and actuator communication. Implemented HDOP-based GPS localization quality gating to prevent navigation on unreliable position fixes.

Continuous Improvement

Numerous reliability and performance improvements across the stack: fixing edge cases from field deployments, tuning parameters for new sites, and hardening the system for unmonitored autonomous operation.

Results

  • TVS 2-Wheeler Factory, Hosur: MMR deployed in an active manufacturing environment, autonomously moving materials across the factory floor
  • Four Lawn Sites: Autonomous Lawnmower deployed with field-validated autonomous missions across multiple properties
