Smart Toilet

IoT-Enabled Automated Public Hygiene System

IoTEmbedded

Problem

Public toilets in India face severe hygiene and water waste challenges. The Kerala Government posed a Smart India Hackathon problem statement: design a system that automates toilet operation, reduces water consumption, and improves cleanliness.

Approach

Hardware System

  • Hydrophobic coating on the toilet bowl to reduce water needed for flushing
  • IR sensor-based automation for bowl opening and flushing, requiring no user contact
  • UV sanitization activated after each use for bowl disinfection
  • ESP32 microcontroller orchestrating all subsystems via logic similar to PLC ladder programming

Mobile Application

Built a Flutter + Firebase app that displays:

  • Nearest available toilet with real-time occupancy status
  • Usage statistics and maintenance alerts after configurable usage thresholds
  • Designed for solar-powered operation at remote public facilities

Results

  • Passed 2 rounds of the Smart India Hackathon
  • Hands-on learning in hardware integration, embedded systems, and ESP32-Firebase connectivity
  • Complete system from CAD design through firmware to mobile app
