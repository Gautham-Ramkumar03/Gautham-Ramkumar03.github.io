Nissan Data Pipeline

End-to-End Road Infrastructure Monitoring System

Deep LearningComputer VisionEdge AIProduction

Problem

Nissan-Fujitsu needed a prototype system to automatically monitor road infrastructure conditions across Japanese road networks using survey vehicles, detecting cracks, potholes, lane degradation, and other defects with GPS-tagged locations.

Approach

Auto-Annotation Pipeline

Bootstrapped the dataset using a lightweight YOLOv8 model as a pseudo-labeler, eliminating the majority of manual annotation effort. Combined the RDD2022 public dataset with custom frames from Japanese road footage and field-collected data.

Detection Models

Trained two specialized models:

  • YOLOv8m Detection (6 classes): cracks, poles, potholes, lane blur, crosswalk blur, manholes
  • YOLOv8s-OBB (2 classes): lane markings and dotted lanes with oriented bounding boxes for geometry extraction

DeepStream Edge Inference

Built the on-vehicle pipeline on Jetson AGX Orin with:

  • Three e-con monocameras (Argus CSI) + one 4K USB camera + ZED X stereo pipeline
  • GNSS NMEA synchronization per-frame across all outputs
  • Proxy-trigger architecture reducing GPU usage from 99% to under 14%
  • Hardware H.265 encoding in lossless CQP mode with automatic file rotation

Azure ML Training Pipeline

Multi-node MPI cluster training with human-in-the-loop review cycles feeding back to retraining. Post-hoc pole classifier for false positive elimination.

Cloud Visualization

Azure Blob Storage with folder-size-based upload triggers. Visualization renders GPS-tagged detection overlays on map tiles for geospatial road condition analysis.

Results

  • 5 independently built systems forming a complete pipeline
  • 8 detection classes (6 standard + 2 oriented bounding box)
  • 100% of detections GPS-tagged at inference time
  • ~85% GPU reduction via proxy-trigger architecture
  • Continuous operation on Nissan survey vehicles across Japanese road networks
