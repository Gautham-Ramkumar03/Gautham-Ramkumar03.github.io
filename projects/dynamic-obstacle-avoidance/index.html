MPPI Obstacle Avoidance

Model Predictive Path Integral Controller for Dynamic Environments

ControlPerceptionROS2Production

Problem

Autonomous robots operating at construction sites and factory floors encounter unpredictable obstacles: workers, vehicles, equipment. The robot must navigate around these obstacles in real-time while following its planned path, without human supervision.

Approach

Perception Pipeline

Raw 3D point clouds from the Livox Mid-360 LiDAR are transformed, filtered, and projected to generate 2D obstacle scans. Euclidean clustering extracts individual obstacle footprints and populates the local costmap in real-time.

MPPI Controller

The Model Predictive Path Integral (MPPI) controller samples thousands of candidate trajectories forward in time, scores each against the costmap and reference path, and selects the optimal control output. This sampling-based approach naturally handles non-convex obstacle configurations without gradient computation.

Custom Kinematics

The controller was tuned for a 4WD bicycle kinematics model with T-pivot front axle steering, a non-standard configuration that required custom constraint definition for smooth, reliable path following at the platform’s operating speeds.

Results

The obstacle avoidance stack enabled truly unmonitored autonomous deployments at construction and factory sites. The robot reliably navigates around both static and dynamic obstacles while maintaining smooth path tracking.
